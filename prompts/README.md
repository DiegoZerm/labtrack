# Prompts del taller

Copia primero `00-contexto.md`. Después envía un solo prompt por etapa, revisa lo que el agente cambió y ejecuta la comprobación antes de continuar. Los prompts son independientes de la marca de la herramienta de IA.

| Etapa | Archivo | Resultado |
|---|---|---|
| Contexto común | [00-contexto](00-contexto.md) | Reglas de trabajo |
| Requisitos | [01-requisitos](01-requisitos.md) | Historias y criterios verificables |
| Diseño | [02-arquitectura](02-arquitectura.md) | Arquitectura, ERD y contrato |
| Proyectos | [03-proyectos](03-proyectos.md) | Primer flujo persistente |
| Experimentos | [04-experimentos](04-experimentos.md) | CRUD, filtros y permisos |
| Pruebas | [05-verificacion](05-verificacion.md) | Evidencia y correcciones |
| Docker | [06-docker](06-docker.md) | Comprensión y reproducción de Compose |
| Cambio de requisito | [07-evolucion](07-evolucion.md) | Campo nuevo con migración |
| Diagnóstico | [08-depuracion](08-depuracion.md) | Resolver un error concreto |
| Entrega | [09-entrega](09-entrega.md) | README y demostración |

En `00-inicio` proyectos y experimentos responden 501. En `01-proyectos` solo experimentos. En `02-completo` revisa la solución o realiza la ampliación; no pidas regenerar lo que ya funciona. La infraestructura de Docker está preparada en todos los paquetes para permitir elegir ruta desde el inicio.

Pregunta de revisión al terminar cada etapa: «Explícame qué archivos conectan el botón Guardar con la base de datos. Después pregúntame algo para comprobar que lo entendí».
