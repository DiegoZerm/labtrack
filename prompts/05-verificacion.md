# 05 · Verificar y revisar

```text
Revisa LabTrack contra docs/02-arquitectura.md y la rúbrica.
Primero lee el código y las pruebas; después ejecuta las comprobaciones.

Comprueba autenticación, cierre de sesión, CSRF, origen permitido,
permisos entre dos usuarios, CRUD, filtros, validación, resumen y persistencia.
Comprueba las migraciones, incluyendo aplicar head dos veces.

Para cada problema: indica el requisito afectado, pasos de reproducción,
resultado esperado y observado, causa con evidencia y corrección mínima.
No reescribas la aplicación ni agregues funciones para resolver un fallo.

Entrega el comando y resultado real de cada comprobación. Diferencia pruebas
automatizadas, pruebas manuales y puntos no verificados. No declares que
Docker, Windows o un servidor remoto funcionan si no los ejecutaste ahí.

Al terminar, hazme tres preguntas sobre el recorrido de una petición,
los permisos y la persistencia para comprobar que entendí la solución.
```
